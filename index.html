功能说明 · 今日要闻工作台（使用手册）

纯静态页面：文稿、人声、配乐、字幕、封面、卡片、成片全部在本机浏览器里生成，不登录、不写回仓库、不依赖云端出片。所有设置与当前稿存在浏览器本地（localStorage / IndexedDB），换浏览器或清缓存才会丢。

一、第一次用，按这 8 步走

  1. 打开页面 → 左侧 01 数据 确认期号 / 日期 / 数据源；顶部绿字应显示「数据契约就绪 · N 道硬闸 全绿」。
  2. 02 文稿 写开场、逐条标题与摘要、片尾。每条一行「标题。摘要」；＋ 添加一条 / ＋ 插入 加的是空白待填条，不填内容不计数、不进口播、不进封面；填了才生效。
  3. 03 封面 选主题 / 五套模板（默认等权列表）/ 尺寸 / 条目分隔 / 展示条数（1–10）/ 焦点小节标题开关。删掉几条文稿后，只要剩余 ≥10 条，封面仍可点满 10 条。
  4. 09 文字排版 集中调字体、字号、字间距、行间距、粗细、颜色、正文背景色；03/04 区的「去 09 区」按钮可直达。
  5. 05 人声 选音色 / 语速 / 音量 → 点「逐句合成到人声轨」。只重合成改过的句子，结果进本机缓存；合成完可点播放试听。
  6. 06 配乐 试听 → 「设为背景」；混声区三人声音量 / 配乐音量 / 总增益，预览与导出同一套。
  7. 07 字幕 设字号、字色、底色与透明度、显示行数（默认 5）、排列方式（默认「从最上面开始」）。文字超过显示行数时自动向上滚动，末尾几行始终可见，不会把超出的字丢掉。
  8. 08 导出 先在「导出格式」下拉选格式，再点红色主按钮。只有视频格式才会用到人声，图片 / 字幕 / 文稿 / 配置都是直接下载。

二、左侧十个区分别是干什么的

  • 01 数据：期号（可编辑，「第3期」自动规范成「第03期」）、日期 / 星期 / 节气自动取当天、文稿 sheet 与封面 sheet 名锁定、数据源留底。
  • 02 文稿：开场白、资讯窗口说明、逐条正文、片尾；「口播生效条数」控制念几条，「使用全部数据」一键全量；「全宽沉浸编辑」可拖拽排序、置顶、删除、Alt+↑/↓ 移动、Esc 退出。
  • 03 封面：10 套主题（含设计稿 A/B/C/D 四套）、五套模板（等权列表 / 语义编排 / 榜单 / 极简列表 / 报头重点）、五种尺寸、九种条目分隔、条目间距（三档预设 8/16/28 或直接填 px，五套模板同源）、报头、期号、水印、封面展示条数。
  • 04 卡片：模板、分类纹样、主题与尺寸共用 03 区；上一张 / 下一张 / 跳到第 N 张；文字设置统一在 09 区。
  • 05 人声：音色、语速（默认 1.00×）、并发路数（默认 6，自适应降速）、逐句合成、增量重合成、试听（优先播缓存，点击即反馈）。
  • 06 配乐：内置配乐 / 自定义上传 / 恢复内置 / 不配乐；试听、设为背景；人声 / 配乐 / 总增益三条滑杆实时生效。
  • 07 字幕：开关、烧录 / 软轨 / SRT、字号、字色（默认 #E6CF5C）、字间距、显示行数 1–5、底色样式与透明度、位置、逐字开关、排列方式（从最上面开始 / 从下往上滚动）。
  • 08 导出：一个下拉 + 一个主按钮。格式见下一节。

三、导出格式清单

  • 视频：MP4（H.264/AAC，浏览器不支持时自动回退 VP9/Opus 的 WebM 离线编码）、WebM。
  • 音频：MP3（真编码，不是 JSON）、WAV（按当前语速 / 音量重新混音的 PCM）。
  • 字幕：SRT（真时间轴）、ASS（含卡拉 OK 逐字标签）。
  • 图片：封面 PNG、当前卡 PNG（切到哪张导哪张）。
  • 文稿 / 配置：Markdown、render_manifest.json、data_source.json。

预览前已逐句合成过人声时，导出会直接复用已合成音轨，提示写「正在复用预览前已合成的人声轨」，不会重新请求人声接口；后台成片备好后点导出是 0 编码直接下载。改一句稿只重算一句。

四、字体：为什么有「未安装」，能不能用命令装

浏览器不能把字体装进操作系统——这是沙箱限制，页面只能：① 用随包内置的 woff2；② 用系统已经装好的字体；③ 用你上传到本页的字体文件。09 区「字体安装助手」给的是给你复制到本机终端执行的命令，不是页面偷偷去装。

  • 最省事（推荐）：09 区「＋ 上传字体文件」选 .ttf/.otf/.woff2，存进本机 IndexedDB，立即生效、刷新仍在，不用装系统、不用重启浏览器。
  • 装到本机：点上方扩展字体的官方链接下载 → 放进同一个 fonts 文件夹 → 09 区选好系统点「复制批量安装命令」→ 在 PowerShell / 终端里粘贴执行 → 重启浏览器再刷新本页，字体才会出现在候选里。
  • 放进站点：把 woff2 放进仓库 assets/fonts/ 并在页面字体表里注册，全站访问者都能用。注意授权：得意黑、霞鹜文楷、站酷系列等开源款可以；MiSans / HarmonyOS Sans / OPPO Sans / 阿里巴巴普惠体等厂商字体须按其官方许可使用，不能随包再分发，所以没有硬塞进包。

六、部署与排障

  • 仓库根目录放完整包全部文件，.github/ 与 assets/ 别拍平；Settings → Pages 选 Deploy from a branch / main / (root)，看到绿条「Your site is live at …」才算发布成功。双击 deploy.bat 可用 Token 一次推送并自动开启 Pages。
  • 配乐不是 404，但停在 0:00 不播放 / 提示整体超时：几乎都是线上还放着旧的 5.5MB 文件。本版把 mp3 压到约 320KB（40 秒循环、64kbps），只传「只替换配乐文件_内置配乐」包里的那一个 mp3 覆盖 assets/bgm/内置配乐.mp3 再 Ctrl+F5 即可，不用动别的文件。取文件超时会自动回退直连流式播放，诊断行会写明是 404、超时、解码失败还是自动播放被拦。
  • 预览配乐没声音 / 一卡一卡的：试听与预览现在共用同一份「一次性取完的」配乐文件和同一个音频上下文；若仍无声，看 06 区状态行会写明取文件结果。自定义音频刷新后地址会失效并自动回退内置配乐，重新选一次文件即可。F12 可跑 window.__bgmDiag() 看当前播放源与音频上下文状态。
  • 配乐试听报「取不到文件 / HTTP 404」：说明重建仓库后只传了 index.html + vox_export.js，漏了 assets/bgm/内置配乐.mp3。补传 assets/bgm/（和 assets/fonts/）或用完整包重来。
  • 改了没生效：先 Ctrl+F5；脚本引用带 ?v=9 版本号，正常不用手动清缓存。
  • 导出没反应：看导出区提示文字；若写「正在复用…」说明在正常编码；若写失败原因按提示处理。非视频格式（PNG/SRT/MD/JSON）本就不碰人声，也不会弹「合成人声」。
  • 在线真人声走公共 TTS 接口，网络不通时会失败并给出提示；本机试听可用已缓存人声或设备音色兜底。
